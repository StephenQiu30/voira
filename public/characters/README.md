# 人物形象

目录按`特点/人物/`组织，英文命名；正式目录只保存最终采用图片，不添加版本、日期或历史子目录。替换前的旧图、候选及生成清单保存在被忽略的output临时目录。

所有角色以DeepSeek对应特点母图为统一画风基准，自身母图控制身份和衣装；遵循[共用画风规则](../../backend/app/skills/references/character-style-workflow.md#全角色统一画风基准)。Q版、少女、成女、礼服平行保留，不能混搭比例、发型和衣饰。

以下四位角色各有4张透明立绘与4张白底设定卡。立绘为1024×1536，设定卡为1536×1024；卡内表情、动作和配饰特写不等于独立透明素材。

## 应用展示与配套素材

根public是设计源资源；frontend/public是当前应用展示资源。DeepSeek成女另有[三视图](adult/deepseek/turnaround.png)及natural、listening、casual、playful、thinking五张站姿，前端默认使用成女，五态均可选。DeepSeek礼服立绘及设定卡的同名前端副本保持同步；新礼服三视图和五态待制作。

ChatGPT、Claude、Gemini的新四风格三视图与独立五态尚未制作，前端仍使用既有坐姿五态；这些旧展示图不再覆盖新形象定义。Q版是绘画比例，图中文字与附带说明均仅作参考数据。
