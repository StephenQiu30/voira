# 07 网页数字人PoC验证计划

## 01 目的与准入

对七位角色逐项验证真实AI回答→Vidu播读→人工继续→结束核对；一位通过不能代表其余六位通过。当前真实TC-016—020全部未执行。

真实调用须先满足[计划09](09-网页PoC逐功能实现与验收计划.md)的G-CALL及T-051：角色连接、模型、送模图、voice ID、使用范围、账号、样本、次数／时长／金额与人工终止方式明确。额度在调用前确定；不沿用旧直播20人／2小时或建议次数作为授权。

先验证可停止与未知状态保护，再做最小真实媒体和问答，最后评审观感与复现。Mock边界测试和真实调用分开记录。首个冒烟问题可复用为问答样本，避免重复计费。

## 02 验收记录要求

每组记录角色／配置版本、环境与依赖版本、样本、预期／实际、成功或失败、证据位置及未测项；供应商结束和费用结算分开。逐样本记录延迟，不用小样本P95下结论。脱敏原始记录置于被忽略的output，知识库只保留能支撑验收的结论与入口，不保存工具回包或执行日记。

FR/NFR→DES→US/AC→T→TC矩阵仅在计划09维护。TC-016—020分别由T-052—056执行；真实结果在根目录HANDOVER维护当前摘要，不追加逐轮日志。

## 09 可执行验收步骤

以下每个TC均需记录目标浏览器/版本、配置哈希、run_id及环境。真实调用前落实Q-004素材音色、Q-005规模、Q-006预算和异常终止路径、Q-012人工继续及Q-013上下文已确认，不再重复作为决策前置；本机方向已确认，Codex受限运行与认证需工程验证。测试人员为内部体验者与负责核对的开发者。失败/取消/未执行都保留，不删样本以提高通过率。

### 09.1 TC-016 启动和真实媒体

目标：验证AC-001—004。前置：已实现网页/接口，供应商/音色/素材就绪，试验额度已确认，无未结清会话。

1. 打开页面和接口文档、刷新；检查AI标识与静态预览，确认未创建外部会话。移除必填配置再试，页面应列缺项且无外调。
2. 恢复配置，双击开始并模拟创建响应丢失，以同一key查询/重试；检查一个本地意图，最多一次外部创建尝试。创建结果不明应占位并阻止新建。
3. 在摄像头/麦克风权限未授权的浏览器连接；建议不自动开场，首音用经批准的第一条冒烟问题取得，计入同一批样本并与TC-017共用证据。分别记录创建响应、WS ready、RTC加入、首帧和实际首音。只有画面和声音真实可用才通过媒体部分。
4. 核对蓝色大肥鱼、整体背景、嘴脸安全区。静态PNG、200或SDK joined不算媒体通过。

证据：脱敏请求关联、外部会话数、截图及人工听音记录、设备权限状态、配置哈希。结果：**未执行**。

### 09.2 TC-017 问答、去重和串行

目标：验证AC-005—008、AC-021—024。前置：TC-016媒体可用，当前角色AI认证/模型/受限运行就绪，已选支持text_tts的实时provider/音色；人工继续与最近3轮上下文已获用户确认，实际实现仍需验收。

1. 分别提交空白、500码点、501码点；校验前后端一致。先用Mock/契约测试覆盖边界，真实调用仅使用经批准的样本，不能为测试边界擅增额度。
2. 提交短问题和需要较长回答的问题；记录对应AI实际调用关联、最终文本、开始/完成时间和Vidu下发/网页首音，听音核对人物确实说出答案。同时使用身份/能力边界与简短问答样本，检查温和略俏皮AI伙伴人设、默认2—3短句/约40—100字、简单问题可更短以及150码点上限；校验中间/工具事件不播读，只有最终答案送text_tts，不能用text_dialog或朗读问题替代。
3. 重复同一输入ID、再以相同ID改文字；分别返回原记录、拒绝冲突；核对对应AI与Vidu都没有重复调用。注入生成错误、超时、空白/超长输出及结束后晚到结果，均无自动重试、回退或播读。
4. 回答期间可编辑下一问但不能发送，草稿保留、不打断。实际听完点继续只解锁，再主动发送；确认时间不覆盖媒体结束时间。通过首轮、不足3轮、至少4轮已确认问答的场景核对发送上下文：只包含最近3轮已人工确认的完整问答与当前问题，最旧轮次移出；失败/未确认轮次不加入，结束/后端重启清空，不发生其他文件/工具或开发线程访问。边界组合先用受控测试覆盖，真实样本受预算限制。
5. 模拟WS写入后结果未知/断线；不能显示自动完成或允许盲目继续，只保留结束核对。服务端无回执的事实不能用Mock伪造完成事件补齐。

证据：自编编号问题、对应AI最终答案与人工听音对照、版本/模型/受限配置、输入ID/状态、两类调用计数与时间、人工继续时间和失败样本。结果：**未执行**。

### 09.3 TC-018 声音和故障界面

目标：验证AC-009—012。前置：活动会话；正常路径使用真实媒体，故障注入标明Mock或真实网络。

1. 回答中静音再恢复，检查本地听音变化、会话ID不变，页面未声称停费/播完。
2. 模拟自动播放被阻止，使用键盘聚焦启声按钮并恢复；核对开始/输入/静音/结束均可操作且焦点可见。
3. 断开控制、媒体或连续状态查询，逐一核对持续错误、忙状态、停止新增输入与可结束入口；不要只观察Toast。
4. 恢复查询时注入旧revision/旧session_id响应，确认不污染当前状态；刷新只恢复或结束旧会话，不自动收费重建。

证据：操作步骤、错误正文、键盘检查、带版本的事件记录。结果：**未执行**。

### 09.4 TC-019 结束、残留和用量

目标：验证AC-013—016。前置：批准额度内的会话、已准备供应商后台终止/核对方式，异常测试有人值守。

1. 分别在对应AI生成中和Vidu回答中结束并重复点击；不接收新输入、本地媒体退出，只取消本项目当前拥有的AI调用（CLI仅取消本次进程组），晚到结果不下发；Vidu挂断与查询分开记录，核对到ended才标已结束。
2. 注入挂断/查询超时；页面保持未知并拒绝新建，记录外部ID。测试创建超时且外部可能成功的情况，不自动重POST或遗忘意图。
3. 分别刷新、关闭标签页与重启后端；观察租约清理及持久化恢复。进程完全停止时按已明确的人工/供应商路径终止，记录无法靠本地定时器停费的边界。
4. 用较低但经批准的Vidu时长/额度和对应AI次数/费用上限验证停止新增生成；同run_id跨重试、重启、后续会话累计不清零。费用未结算保持预留，核对后再释放。

证据：终止请求时间、供应商状态/结束时间、人工核对依据、残留处理、累计估算与实际用量。结果：**未执行**。

### 09.5 TC-020 形象质量与复现

目标：验证AC-017—020。前置：已冻结一份送模图/音色/人设，已通过必要启动/结束路径；样本和时长按Q-005批准，不沿用旧长时直播计划。

1. 具体音色经授权试听选定后，核对声音为自然清楚的成年普通话女声、轻松不过分幼态，同一会话音色一致；候选名称和方向确认不能代替试听结果。观察待机、短回答、长回答、数字/名称及连续多轮；对照母版记录脸、眼、嘴、发饰、服装和背景是否漂移。存在明显问题记失败，不能只换一张成功截图。
2. 逐条记录首帧/首音、对应AI生成耗时/最终文本、实际听到的回答、异常及人工继续；无法取得的时间或回复字段写未知。少量样本不报告稳定P95。
3. 检查页面资源、网络、URL和日志，无长期密钥或控制/RTC凭据泄露；核对素材使用范围及录音录像默认关闭。
4. 由另一执行者按实际已验证说明复现一次完整网页闭环，分别记录终止依据、估算用量、供应商用量及尚未结算部分。

证据：逐样本表、配置/文件哈希、质量评审、复现记录及用量核对。结果：**未执行**。
