# 00 技术选型依据与参考来源

## 01 采用结论

研究日期为2026-10-25—26，以下是既有来源核验的结论，不是今天重新验证的供应商能力。当前需求以[需求索引](../requirement/01-数字人MVP需求草案.md)为准：网页优先、Vidu数字人、七角色对应AI。本文件合并原RES-001—010的有效结论；旧编号保留占用，原始采集与源码快照不在知识库维护。

| 决策 | 依据与限制 |
|---|---|
| Vidu实时数字人 | [官方概述](https://platform.vidu.cn/vidu-stream/doc)、[实时参数](https://platform.vidu.cn/vidu-stream/doc/s2-avatar/realtime/parameters)：创建／查询、WS控制、RTC媒体分别处理；异步MP4接口不能替代实时会话。text_tts与text_dialog不同，不假定有逐句播放完成回执；实际账号、组合和媒体须实测 |
| 自有图片驱动 | [上传文档](https://platform.vidu.cn/vidu-stream/doc/image-upload)描述单人资产及处理状态；保存本地母版与文件哈希，云资产有生命周期，上传成功不代表真实保形通过。采用素材／声音规则见design03/20 |
| 暂不自建本地驱动 | [MuseTalk](https://github.com/TMElyralab/MuseTalk)、[LiveTalking](https://github.com/lipku/LiveTalking)需要另验硬件、依赖和许可；公开帧率非本项目成绩。[Live2D](https://github.com/Live2D/CubismWebSamples)需要真实模型／纹理／动作资源，现有PNG不等于可驱动模型 |
| 保持简单本机链路 | FastAPI编排、HTTP快照、单进程与拟建SQLite意图账本；先补去重、恢复和结束核对，不因参考项目存在SSE／队列／RTMP就照搬 |
| 外部直播后置 | [抖音评论能力](https://developer.open-douyin.com/docs/resource/zh-CN/interaction/jierushuoming/hudongshuju/pinglunshuju)不证明可取得任意房间自由评论／礼物或推流权限；OCR只是候选，不能当稳定官方接入 |
| 费用调用前核价 | [Vidu价格](https://platform.vidu.cn/pricing)与实际账号／地区核对，旧研究估算不作为当前报价或批准额度。Vidu时长与各AI用量分别累计 |

LiveAvatar、Tavus、Synthesia的公开页面仅提供界面与接入形式参考；没有在本项目创建其真实对话或测性能。[LiveAvatar生命周期](https://docs.liveavatar.com/docs/full-mode/lifecycle.md)与[Tavus结束接口](https://docs.tavus.io/api-reference/conversations/end-conversation)不能替代Vidu的实际契约。

## 04 资产制作方法

采用角色定义→身份基准→三视图／设定卡→五张独立坐姿→逐张验收的流程；身份参考、姿势参考、细节与文件打包分别控制。最终Skill及排除规则见[视觉设定20](../design/20-人物三视图视觉设定.md)，不复制平台私有提示词或保留每次生成日记。

公开参考：[RunningHub三视图与特写](https://www.runninghub.cn/ai-detail/2049134928775880705)、[角色设定多维资产](https://www.runninghub.cn/ai-detail/2043603134685126657)、[火山引擎多参考生图指南](https://docs.volcengine.com/docs/Largemodelofimagegeneration/Intelligentimagegeneration?lang=zh)。这些支持输入分责与输出拆分，不证明批量稳定性；公开三视图作品出现近似侧面代替背面及标签拼写问题，因此成图仍须逐项核验。

材质参考[Blender Principled BSDF](https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/principled.html)：区分金属、织物、漆层和粗糙度；这是美术描述依据，不代表已制作3D资产。Casting只读到公开布局，私有正文未取得；平台入口和静态样例不等于调用成功。
