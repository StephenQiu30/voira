# 26 测试用量与预算控制

需求编号：**FR-025**。范围：**网页PoC P0**。

## 01 问题与来源

内部验证者需要在批准范围内测试，避免重试和未知会话无限消耗。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。

## 02 范围与边界

不建设商业计费后台或购买额度；不在文档/聊天中要求粘贴密钥。

依赖或协作：FR-007/008/019。

## 03 功能要求

1. 分别累计Vidu时长/费用及各AI服务尝试数/费用，按服务与实际模型核价，同run_id不因重试、刷新或重启清零。
2. 上限触达或余额不足时停止新增生成，必要时结束会话；估计与供应商结算分别记录，未知不得写零。
3. 终止或结算未知时保留额度占用并核对；本地计时器和进程取消不保证上游立即停费。
4. 此前15分钟/12次及2问冒烟、10问短测均只是建议，用户未批准；不得据此执行调用。

## 04 确认状态与剩余问题

控制用量在PoC范围；账号、次数、时长与金额实际调用前再定。

关联问题：Q-005/006。
