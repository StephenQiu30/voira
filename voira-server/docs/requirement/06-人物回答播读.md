# 06 人物回答播读

需求编号：**FR-005**。范围：**网页PoC P0**。

## 01 问题与来源

体验者需要听到人物针对问题作出的实际回答。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。

## 02 范围与边界

不开放用户手写台词播读入口，不触发动作/换装。

依赖或协作：FR-019/020/022/023。

## 03 功能要求

1. 只把[FR-031绑定的对应AI](32-七位角色与AI服务绑定.md)成功产生并校验的完整最终答案交给Vidu text_tts；不朗读用户问题、不让Vidu再次生成答案。
2. 同一输入只形成一次播读意图；无成功业务回执时不能显示已受理或已播完，未知不自动重播。
3. 生成文本可以标为“生成的回答”，不得冒充已播放字幕；实际声音和口型需真实观察。
4. 正常后续输入不得打断当前轮；轮次释放由独立FR-023负责。

## 04 确认状态与剩余问题

问答模式与AI生成／Vidu播读分工已确认；T-118扩展到七位对应AI，真实效果未验证。

关联问题：Q-004/006。
