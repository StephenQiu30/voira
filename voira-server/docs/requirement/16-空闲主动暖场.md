# 16 空闲主动暖场

需求编号：**FR-015**。范围：**后续候选，当前不实施**。

## 01 问题与来源

未来无用户互动时，操作者可能希望人物主动讲话。

来源：参考图文/源码研究及已明确后置的历史需求，2026-10-25整理。

## 02 范围与边界

当前网页PoC不自动暖场，不能从参考截图推导为已获准。

依赖或协作：FR-012/025。

## 03 功能要求

1. 只有队列空闲且显式启用时才触发，间隔和费用受控。
2. 用户互动、禁用和会话结束具有明确影响，结束后不得自动恢复暖场。

## 04 确认状态与剩余问题

后续候选，当前不启用。

关联问题：后续另定。

## 05 验收与追溯

仅登记需求候选；未分配当前DES、US/AC、实现任务或真实TC，不以未设计阻塞网页PoC。
