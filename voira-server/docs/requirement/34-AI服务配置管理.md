# 34 AI服务配置管理

需求编号：**FR-033**。用户要求为AI接入补充管理页面；七角色与服务映射沿用[FR-031](32-七位角色与AI服务绑定.md)，只新增管理界面设计，不据此宣称服务接通。

## 01 目标与范围

以预设引导接入：选择服务预设、填写必要凭据、选择模型、保存连接，再主动检测；同时提供服务列表、角色就绪和用量限制。七项服务分别管理，ChatGPT对应OpenAI；不能跨品牌绑定或将一项成功显示为七项可用。管理员用户管理已按[FR-034](35-管理员用户管理.md)扩展设计；共享连接配置、检测及限制仅管理员可操作，普通用户只读本人可用服务与用量。认证与远程部署仍未实现。

## 02 功能规则

1. 区分未配置、已保存待检测、检测中、检测通过、认证失败、结果未知、已停用；列表读取另有加载、空态、错误与重试。
2. 预设负责提供服务名称、认证方式、协议及默认地址等配置，用户无需从空白表单填写技术参数。可复用已保存连接；同一服务允许保存多个连接，每位角色只启用一个。预设与模型选择受后端适配能力限制，未支持项显示原因；高级自定义地址须由后端校验，不能通过改名将其他品牌模型绑定到该角色。
3. API密钥通过管理表单一次性提交后端，保存后只显示是否已配置及替换入口；不回显、不写浏览器持久存储。已有凭据可复用后端引用，本机认证只在对应适配器支持时提供。预设不含秘密，保存为独立连接及版本；模板升级不覆盖已保存值，切换预设先处理未保存修改。连接、模型或凭据改变后旧检测失效；保存本身不发起模型或Vidu调用。
4. 检测只针对选定连接；调用前显示请求范围和可能费用，用户主动开始。检测中防重复操作，未知结果不自动重试；错误持续显示并给出可执行下一步。检测通过不等于人物媒体就绪。
5. 活动会话固定旧连接、模型及媒体配置。编辑新版本仅影响之后创建的会话；使用中的连接不能停用或删除，先结束并核对当前会话，不在生成或播读中热切。
6. 角色就绪分别核对AI、送模素材、音色与额度；Kimi／Qwen保留各自缺图状态。配置清单不产生收费调用。
7. 用量区分AI请求、Vidu时长与实际费用；未知保持未知，重试计入次数。限制未填或保存失败保留原值；暂停新请求不等于供应商已停止计费。沿用FR-025，不建设充值和商业结算。

## 03 确认与验收

2026-10-26用户明确采用参考CC Switch的预设接入方式；具体预设目录、表单、版本生效规则和管理权限仍为设计草案。Q-014继续维护七项真实连接缺口，预算归FR-025。此文不新增运行接口，后续实现前补齐共享design03契约。关联[DES-039](../design/32-个人中心与AI接入管理界面.md)、[US-012／AC-067—073](../prd/01-网页数字人PoC产品与验收标准.md#15-个人中心与ai接入管理页面)、[计划09](../plan/09-网页PoC逐功能实现与验收计划.md#11-个人中心与ai管理的设计验收)。
