# 00 知识库导航

## 01 产品与阅读路径

声伴Voira是网页优先的数字人交流应用：七位形象分别绑定对应AI，同一时刻与一位交流，由Vidu播读和驱动画面。人工听完后继续，模型只保留最近三轮已确认问答；当前页面完整记录单独维护。直播／评论后置，群聊、原生应用与长期历史未进入当前范围。

1. [需求索引](requirement/01-数字人MVP需求草案.md)：34项独立需求、当前18项、后置13项及3项管理页面设计、共享约束及待决问题。
2. [功能设计索引](design/00-功能设计索引.md)：按职责找到设计；先看[AI与数字人协同](design/31-AI服务与数字人协同设计.md)，技术细节查[共享契约](design/03-Vidu网页PoC最小业务设计.md)。
3. [产品与验收标准](prd/01-网页数字人PoC产品与验收标准.md)：用户故事、AC和边界。
4. [实施计划](plan/09-网页PoC逐功能实现与验收计划.md)与[真实验收场景](plan/07-网页数字人PoC验证计划.md)：任务依赖、追溯和通过条件。

当前已实现静态人物选择页与内部素材任务准备服务，真实AI问答和Vidu链路未验收。实际任务状态看[BLACKLOG](../BLACKLOG.md)，可用能力和验证边界看[HANDOVER](../HANDOVER.md)。

## 03 维护规则与工程入口

在Obsidian打开docs。requirement保留一功能一文档；design按稳定职责合并；prd维护验收；plan只留实施依赖和测试规格；research只留有用结论及来源；templates仅保留规范与最小写法。

知识库不接收逐轮交付日志、生成过程、OCR、抓取回包、旧稿全集或重复提示词。历史由Git和必要本地恢复副本承接，不再建docs归档目录。具体规则见[文档规范](templates/06-文档编写规范.md)。

[PROJECT](../PROJECT.md)维护技术栈与目录，[DESIGN](../DESIGN.md)维护通用视觉，[AGENTS](../AGENTS.md)维护执行与提交。开发入口：[前端](../frontend/README.md)／[后端](../backend/README.md)，规范：[前端](templates/07-前端开发规范.md)／[后端](templates/08-后端开发规范.md)。
