```text
voira/
├── AGENTS.md                       # Agent 工作入口
├── BLACKLOG.md                     # 唯一任务顺序与状态
├── HANDOVER.md                     # 当前交接

├── frontend/                       # Next.js 目录骨架及规范入口
└── docs/
    ├── .obsidian/                  # 本地知识库配置
    ├── 00-知识库导航.md
    ├── requirement/                # 总索引、单功能需求及history历史快照
    ├── design/                     # 实际交互、接口与数据库设计
    ├── prd/                        # 实际产品需求文档
    ├── plan/                       # 实际执行计划与验证草案

        └── reference/             # 参考源码
```

根目录AGENTS、BLACKLOG、HANDOVER、PROJECT、DESIGN和README是项目入口，位于docs仓库外，由Agent或项目编辑器直接读取。Obsidian中主要阅读docs内部文档；根目录保留相对链接供项目编辑器使用。
