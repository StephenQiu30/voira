# 06 网页文字提问设计

设计编号：**DES-020**；唯一主需求：[FR-004 网页文字提问](../requirement/05-网页文字提问.md)（业务规则及确认状态以该文档为准）。当前网页PoC；关联共享设计DES-014。本设计是T-024文档交付，尚未实现或执行真实调用。

## 01 设计范围与决策

TurnService接受一个显式提交；前端DraftComposer只管理草稿，输入框和当前已提交问题分开。单用户PoC使用单占用槽，替代弹幕队列。

源码依据：[RES-008](../research/07-参考仓库到网页PoC实现映射.md)中的SRC-07/09。这些是固定提交的静态证据；本项目改造建议与上游行为分开记录。公共接口、状态枚举与表结构以[共享设计](03-Vidu网页PoC最小业务设计.md)为唯一契约来源，本文定义本功能责任。

## 02 用户流程与状态

编辑草稿 → trim并校验1—500 Unicode码点 → 创建input_id → 提交 → 显示生成中。期间允许继续改下一问草稿，但提交按钮锁定；输入被接受不表示人物已回答。成功解锁后必须再次主动点击发送。

网络超时先查询当前意图；不换ID自动重试。网页只在会话健康且无占用时允许发送，后端再次检查以阻止双击和陈旧页面。输入失败保留草稿，键盘提交遵守同一规则；中文输入法组合态不能触发提交。

## 03 接口与责任边界

POST /api/sessions/{id}/inputs使用input_id/text；202回InputReceipt，轮询快照取active_input；空白/超长422、忙409、相同ID不同内容409；input_id已存在但属于其他会话也返回409，不返回旧会话内容。发送前把本次文本复制为不可变提交内容，同ID重查不能使用后来编辑的新草稿。

HTTP接口按共享契约各自遵循同源、本机、控制令牌、幂等与错误规则（只读配置查询不要求会话令牌）；不存在的端点不宣称已可访问。内部适配接口是拟实现边界，不额外创建网络服务或脚本。

## 04 数据与生命周期

inputs.id为幂等标识；content_hash基于trim后UTF-8文字，前后端不做不同的隐式Unicode归一化。唯一(session_id,active_slot)保护占用。正文仅内存；刷新可恢复状态，草稿不承诺跨关闭保存。相同文字新ID是新一轮，不做永久内容去重。

如涉及共享表，约束/索引/迁移见共享设计第04节；不为本功能单独复制一套数据库。正文、秘密和恢复元数据分别处理。

## 05 验证与追溯

[最小设计](../design/03-Vidu网页PoC最小业务设计.md)：DES-014；[验收标准](../prd/01-网页数字人PoC产品与验收标准.md)：US-002；AC-005/007/008；[验证计划](../plan/07-网页数字人PoC验证计划.md)：TC-017。真实场景均未执行。

本功能重点：0/1/500/501码点、中文/emoji边界、连续点击、占用中编辑、重新主动提交相同文字与旧响应回流。

跨功能NFR沿用共享设计第05节；静态契约检查、模拟依赖、真实服务与人工评审分开记录。当前TC-016—020全部未执行，详细任务与证据见[计划07](../plan/07-网页数字人PoC验证计划.md#14-参考仓库到逐功能设计)。
