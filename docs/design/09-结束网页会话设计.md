# 09 结束网页会话设计

设计编号：**DES-023**；唯一主需求：[FR-007 结束网页会话](../requirement/08-结束网页会话.md)（业务规则及确认状态以该文档为准）。当前网页PoC；关联共享设计DES-016/017。本设计是T-024文档交付，尚未实现或执行真实调用。

## 01 设计范围与决策

SessionService拥有统一结束路径，清理输入、Codex进程、RTC和Vidu控制；由核对器决定外部终态，不能照搬参考的本地finish即ended。

源码依据：[RES-008](../research/07-参考仓库到网页PoC实现映射.md)中的SRC-08/09。这些是固定提交的静态证据；本项目改造建议与上游行为分开记录。公共接口、状态枚举与表结构以[共享设计](03-Vidu网页PoC最小业务设计.md)为唯一契约来源，本文定义本功能责任。

## 02 用户流程与状态

显式结束/达到上限/租约失效 → 记录结束意图并禁止新输入 → 立即停止本地媒体及本轮Codex → 尽力挂断 → 查询外部状态 → ended或end_unknown。未取回live_id的创建中结束仍保留占用，待返回后清理。

挂断失败、WS关闭或浏览器退房只说明本地动作，不能自动ended；核对未知阻止新会话。后台重启先扫描未决会话，禁止恢复问答/自动重开；全机停止时无法保证定时清理，真实测试须有供应商或人工终止路径。

## 03 接口与责任边界

POST /api/sessions/{id}/end返回202终止中，已确认结束返回200；重复结束幂等。GET快照提供end_evidence/cost_status。后端使用Vidu挂断与查询接口；人工后台核对暂由本机操作者记录脱敏凭据，不增加通用管理后台。

HTTP接口按共享契约各自遵循同源、本机、控制令牌、幂等与错误规则（只读配置查询不要求会话令牌）；不存在的端点不宣称已可访问。内部适配接口是拟实现边界，不额外创建网络服务或脚本。

## 04 数据与生命周期

sessions增加stop_requested_at/end_reason，结束意图在外调前落库。provider_status、ended_at、end_evidence与费用结算分开。结束后清除问答正文，终态与用量元数据保留到核对完成。

如涉及共享表，约束/索引/迁移见共享设计第04节；不为本功能单独复制一套数据库。正文、秘密和恢复元数据分别处理。

## 05 验证与追溯

[最小设计](../design/03-Vidu网页PoC最小业务设计.md)：DES-016/017；[验收标准](../prd/01-网页数字人PoC产品与验收标准.md)：US-004；AC-013/014/015；US-002/AC-023；[验证计划](../plan/07-网页数字人PoC验证计划.md)：TC-019。真实场景均未执行。

本功能重点：连续结束、生成中结束、WS写入附近结束、创建未知、页面关闭、后端崩溃恢复和供应商结束/费用不同步。

跨功能NFR沿用共享设计第05节；静态契约检查、模拟依赖、真实服务与人工评审分开记录。当前TC-016—020全部未执行，详细任务与证据见[计划07](../plan/07-网页数字人PoC验证计划.md#14-参考仓库到逐功能设计)。

确认过的业务选择不重复开放；剩余问题以本功能需求第04节及总索引Q责任路由为准。具体素材/音色、模型隔离与媒体能力仍需验证，账号/测试规模/预算在实际调用前落实。实现须获得后续授权，本轮未写业务代码、迁移或调用脚本。
