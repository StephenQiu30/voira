# Voira人物设计

## 阅读入口

- 当前输出形式和范围：[设计22](../../22-角色选角与CG设定技能.md)。
- 身份、服装与道具锚点：[视觉设定20](../../20-人物三视图视觉设定.md)。
- 五位美术描述：[设计23](../../23-五位角色CG人设与描述.md)；七位完整背景、成长线与关系：[设计24](../../24-七位角色背景与人设.md)。
- 需要查来源真实性时读[RES-009](../../../research/08-Liblib技能与角色CG描述拆解.md)：第二个Liblib技能没有公开正文，本文件不是其原版源码。

## 执行

1. 读取同名角色的原自然姿态和旧卡，并实际查看图片。提取脸、眼、发型、轮廓、衣饰、配色与既有表情；角色资料里的姓名不等于模型厂商身份或能力。不要把其他角色的识别配件套进来。
2. 区分原图可见事实、用户已确认个性、为卡面新增的创作细化。写清简介、性格层次、表达方式、标志动作、表情范围与CG美术描述；细化不是由外貌证明的心理结论。用户要求完整人物创作时，可以补写家庭、关键事件、目标、内心矛盾、弱点、行为触发、关系、成长节点和代表台词，标为原创草案；用户已给定的身份锚点不改。具体年龄/身高、恋爱关系、超能力不因补背景而默认增加，额外物件须标为候选。外部标签与用户角色归属冲突时按用户修正，本项目银紫龙角角色是ChatGPT。
3. 按用户当前请求选择输出。默认三视图与人物卡独立：三视图是纯白、正/90度侧/背、等高等比例、完整全身、脚底对齐、双腿平行和中性站姿；人物卡是一幅主CG配可读的姓名、定位、简介、人设、形象与动作摘要。大脸与九宫格选角组合只在用户明确需要时制作。
4. 用具体材质、主光、轮廓光和表情描述CG效果，保持原画媒介与服装构造。图中三视角共用同一个脸与造型；坐椅时使用同一PROP参考。背景干净，椅子轻度雕花的当前要求见设计20，不能自行放大成王座。
5. 为每张图写明确的参考角色和优先级。直接请求生成时使用可用图像工具，编辑前先查看本地图；仅请求文字或提示词时不额外出图。尊重当前“一位先看效果”边界，不因五位文字完成而自动批量生成或替换素材。
6. 按身份、腿部/脚部结构、侧面角度、服装、配饰、文字和道具逐项目视检查。记录未达成项；只针对实际缺陷调整。保存到新review目录并保留原图，实际提示词写入[提示词21](../../21-人物三视图图片提示词.md)，生成事实进入[素材记录02](../../02-五位角色素材生成记录.md)，状态与验证沿用根BLACKLOG/HANDOVER及计划08。

## 最小提示词结构

```text
任务与输出形式：〔标准三视图 / 独立CG设定卡 / 道具参考〕
参考优先级：〔同名身份原图〕→〔服装/背面辅助〕→〔道具结构〕
身份与造型：〔从该角色读取的具体锚点〕
布局和姿态：〔视角、站姿轴线或该人物的个性动作〕
画风与材质：〔原媒介、局部材质差异、光影重点〕
人物文案：〔仅设定卡需要的已选摘要；逐字提供〕
一致性与验收：〔本次最重要的保留项和具体缺陷检查〕
```

输出时链接图片与详细档案，说明候选状态；第三方例图、内部提示词是否可见、实际用的生成工具分别说明，不将静态样稿当作动态驱动或业务验收。
