## 02 视觉与响应式

复用现用Logo、按钮、头像、主题变量、Noto Sans SC字体和液态玻璃效果；新增单行Field和Switch组件。背景采用原摄影棚的低对比模糊版本，不引入高亮侧灯或动态闪光。黑白灰控件不增加装饰描边，功能焦点继续保留。

桌面以1440px宽为基准：Header、216px设置导航和1096px内容区；长内容允许正常纵向滚动，不牺牲可读性强塞进首屏。手机390px基准、16px页边距、358px内容宽，服务列表改为单列；字段标签常驻，输入16px、按钮44px。头像只作识别，角色就绪页使用单一居中立绘，不出现相邻人物。

明暗主题由图标切换，保留配置、阅读位置与会话；减少动效时取消页面淡入。前端沿用shadcn/Radix的Tabs、Dialog、Switch和表单语义；焦点回到触发点，Tab顺序、Esc关闭、正文错误重试在实现阶段逐项验收。

## 03 用户与会话

用户已确认同时设计管理员用户管理。个人中心按当前账户展示称呼与偏好，普通用户与管理员入口分开；样例身份不代表真实登录，不展示会员等级或云端同步承诺。编辑资料使用Dialog；取消保留原值，输入异常和保存失败在表单内反馈。偏好保存失败要回滚开关并说明原因，不能仅Toast。

本次对话卡按真实会话状态切换为空态／返回交流／查看本次记录；进入设置不销毁会话。返回舞台不强行选择DeepSeek，也不启动新的媒体。Figma使用无会话样例，完整记录仍由设计25负责，不能从本页扩展为长期历史。

## 04 连接管理与状态

采用“预设 → 连接 → 角色绑定”的结构。预设是无秘密的配置模板，连接是用户保存的配置，每位角色只启用一个对应服务的连接。普通用户不需要理解后端引用或编辑JSON。

**主路径：** AI接入 → 选择角色对应的服务 → 添加连接 → 选择预设 → 补齐必要字段 → 保存 → 主动检测 → 设为该角色连接 → 查看数字人就绪。已有连接可以直接选择；检测失败时保留当前启用连接。只有已通过当前版本检测且品牌匹配的连接可新启用，AI启用后仍需通过素材、音色及额度检查才能开始数字人会话。

1. **选择预设：** 默认展示当前服务的可用预设，可搜索名称；显示服务来源、认证方式和适配支持情况。官方API为优先分组，已有本机连接另列；受控自定义为次入口。后续若提供中转平台，必须显示平台与实际模型来源，不能把兼容协议当作品牌。未实现适配器的选项禁用并说明原因。
2. **填写配置：** 顶部显示已选预设与“更换”；预填连接名称和默认参数。常规表单只显示认证所需字段及模型；API Key使用密码输入，已有凭据显示“已配置／替换”，支持复用可用的后端凭据引用。本机连接只展示已注册入口与认证状态，不展示任意命令输入。
3. **高级选项：** 折叠显示服务地址、协议、地区等该预设实际支持的字段；后端校验约束归共享设计03.5。模型来自预设批准列表或适配器查询；不支持查询时提供受校验的模型ID输入，不编造可用模型。保存与检测分开，按钮明确“保存连接”“检测文本连接”，不在选预设时调用模型。
4. **编辑与切换：** 切换预设或离开已修改表单先处理未保存内容；不得把密钥带到其他服务。可保存多份同服务连接，用列表标注当前启用项；启用新版本只影响后续会话，使用中连接不能删除或停用。预设更新显示差异后由用户采用，不悄悄改写已保存配置。
5. **数字人服务：** AI接入页另设Vidu媒体配置入口，与七项回答服务分区；沿用预设及已保存连接的交互，显示独立认证、资产和声音缺项。文本检测只测AI；完整媒体验证需说明费用并主动开始，具体voice ID与送模配置仍按Q-004落实。

桌面在现有内容区使用两步页面，保留返回位置；手机同序单列，不用横向大表格。每步有常驻标题、字段标签与页内错误；切换预设后焦点回到表单标题，失败定位相关字段。搜索无结果提供自定义入口或未支持说明，不能以无结果暗示自动可接入。

参考：[CC Switch添加供应商手册](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/2-providers/2.1-add.md)（2026-10-26查阅）。借鉴其两步选择、自动填写与预设快照；本项目不接管CC Switch或开发CLI的全局配置，不导入个人聊天、MCP或全部供应商目录。以上为Voira设计取舍，具体预设值须实施时按对应服务核验。

| 状态 | 显示与操作 |
|---|---|
| 未配置／清单为空 | 提供“从预设添加连接”；若目录读取失败显示重试，未支持预设显示原因；不把缺连接等同缺人物素材 |
| 已保存待检测 | 明确旧检测失效，当前会话继续使用旧版本 |
| 检测中 | 防止重复点击，展示正在检查文本；不启动Vidu |
| 检测通过 | 只证明本连接的文本检测；显示检测时间和配置版本 |
| 认证失败 | 字段和正文保留原因，允许替换凭据后重新保存；Figma仅用占位文本，不输入真实秘密 |
| 结果未知 | 保留本次请求标识，先核对上游，不自动重发或显示0费用 |
| 清单读取失败 | 页内错误和重新读取；未知不能沿用旧成功状态冒充最新 |
| 使用中／已停用 | 使用中禁止停用、删除和热切；停用后不得新开会话 |

用量展示请求、媒体和费用三个独立口径，未知使用“—／待核对”。上限未填、格式错误、超出允许范围均阻止保存；明确保存不等于开始请求。原型已展示活动会话占用时停用／删除禁用及返回核对入口；无活动会话的完整删除流程仍不在本批状态范围。

## 06 管理员用户管理与权限

**DES-040**对应[FR-034](../requirement/35-管理员用户管理.md)。用户明确要求管理员管理能力；本节替代此前“仅本机个人中心、不含用户管理”的范围假设。沿用同一应用导航和玻璃材质，不增加多租户组织后台。

| 视角 | 可以做什么 | 不包含 |
|---|---|---|
| 普通用户 | 本人资料／偏好、本人用量、获准的AI角色 | 其他用户资料、共享连接编辑和检测、共享额度修改 |
| 管理员 | 用户列表／详情、角色、停用／恢复、共享连接和操作记录 | 他人对话正文、完整密钥、无授权跨用户会话内容 |

列表使用轻量表格，手机折为单列；搜索与状态筛选不修改账户。详情区分账户资料、有效权限、活动会话元数据。添加默认普通用户，创建后待激活，邀请发送与账户激活分别反馈；认证和邀请渠道仍待确认。角色提升说明权限变化，取消不改变状态；失败保留输入、显示正文错误。

停用确认展示目标和活动会话数量。停用后的“已阻止新访问”与“媒体结束待核对”分别表示，只有真实终态依据才能标已结束；恢复要求重新登录，不复活旧令牌或旧对话。最后一位有效管理员不得被停用／降级，并需服务端原子判断。无权限直达管理URL显示拒绝页，不先载入用户清单。

Figma覆盖正常／已停用／待激活／变更角色／停用待核对、搜索空态、读取失败、权限不足与修改失败；代表性操作围绕林小雨、苏晚演示，不进行真实账户写入。普通用户个人页移除共享配置入口；管理员个人页及AI接入列表提供用户管理入口。所有管理动作最终需服务端鉴权、对象隔离和必要操作记录，不能用原型跳转代替。

首次管理员建立、账号认证／会话撤销、并发保护、邀请投递、记录保留期限仍待评审；本轮不展开登录实现、真实邀请或多路数字人并发。后续验收见[PRD第16节](../prd/01-网页数字人PoC产品与验收标准.md#16-管理员用户管理)。
