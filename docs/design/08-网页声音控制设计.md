# 08 网页声音控制设计

设计编号：**DES-022**；唯一主需求：[FR-006 网页声音控制](../requirement/07-网页声音控制.md)（业务规则及确认状态以该文档为准）。当前网页PoC；关联共享设计DES-015。本设计是T-024文档交付，尚未实现或执行真实调用。

## 01 设计范围与决策

RemoteMediaController封装RTC SDK音频能力，前端状态区分用户希望启声与播放是否受阻。参考video默认静音且声音在SDK内，不能只操作video元素。

源码依据：[RES-008](../research/07-参考仓库到网页PoC实现映射.md)中的SRC-04/05。这些是固定提交的静态证据；本项目改造建议与上游行为分开记录。公共接口、状态枚举与表结构以[共享设计](03-Vidu网页PoC最小业务设计.md)为唯一契约来源，本文定义本功能责任。

## 02 用户流程与状态

尝试播放 → 若浏览器限制则持续显示“开启声音” → 在用户手势内恢复实际远端音频 → 成功后更新状态。静音/恢复只控制当前远端音频轨道，不创建、结束或重新发送内容。

恢复失败不能吞异常或显示已启声；正文显示原因和可重试入口。已有声音状态未知时标未知。重复点击不重复入会；按钮键盘可用、有可见焦点和明确标签。静音不释放轮次槽。

## 03 接口与责任边界

本地适配接口为setAudioEnabled(enabled:boolean)和unlockAudio()，返回user_enabled布尔及playback_state枚举enabled/muted/blocked/unknown/error；这是本项目内部契约，具体SDK方法待锁定版本核查。heartbeat.audio_enabled仅上报用户设定的本地启声开关，audio_playback_state另报上述播放状态；未知使用unknown，不能强记为已静音或false。两者均不能证明实际听到。

HTTP接口按共享契约各自遵循同源、本机、控制令牌、幂等与错误规则（只读配置查询不要求会话令牌）；不存在的端点不宣称已可访问。内部适配接口是拟实现边界，不额外创建网络服务或脚本。

## 04 数据与生命周期

用户声音偏好和播放状态驻浏览器当前会话，不入数据库、不修改计费状态。退房移除SDK监听及远端音频资源；切会话后旧Promise不能覆盖新状态。

如涉及共享表，约束/索引/迁移见共享设计第04节；不为本功能单独复制一套数据库。正文、秘密和恢复元数据分别处理。

## 05 验证与追溯

[最小设计](../design/03-Vidu网页PoC最小业务设计.md)：DES-015；[验收标准](../prd/01-网页数字人PoC产品与验收标准.md)：US-003；AC-009/010；[验证计划](../plan/07-网页数字人PoC验证计划.md)：TC-018。真实场景均未执行。

本功能重点：浏览器阻止自动播放、手动恢复、静音恢复、恢复失败、SDK异步失败及退出后残留音频；听见与API成功分开记录。

跨功能NFR沿用共享设计第05节；静态契约检查、模拟依赖、真实服务与人工评审分开记录。当前TC-016—020全部未执行，详细任务与证据见[计划07](../plan/07-网页数字人PoC验证计划.md#14-参考仓库到逐功能设计)。
