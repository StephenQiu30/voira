# 25 会话记录与直播页面结构

## 01 范围

| 设计 | 主需求 | 范围 |
|---|---|---|
| DES-034 本次对话记录 | [FR-030](../requirement/31-本次会话完整对话记录.md) | 当前网页功能，设计完成、会话实现未接入 |
| DES-035 干净播出 | [FR-003](../requirement/04-外部直播输出.md) | 后置实现，预留独立观众视图 |
| DES-036 评论操作 | [FR-010](../requirement/11-外部互动事件采集.md)、[FR-012](../requirement/13-外部消息队列.md) | 后置实现，先评审页面与队列建议 |

延续单人物中心、固定选择几何、明暗摄影棚与轻量液态玻璃。控件复用shadcn/Radix语义。Figma示例不证明真实输入、持久化、评论接入、自动推进或音视频终止。

## 02 场景导航

聊天和直播操作台使用独立场景Tabs。正在聊天时进入直播须确认结束原会话并核对停止；取消保留阅读位置。直播运行／暂停时返回聊天同样先核对结束，未知不能开始新的公开播出。已结束聊天可进入未连接、自动处理关闭的准备页；返回聊天只读记录不自动开启会话。

私人记录、草稿及模型上下文不进入公开播出。收合、主题和面板切换不重建会话；进入操作台不等于开播。独立播出页只订阅指定会话，不自行生成或创建收费人物。路由、鉴权、多视图同步及停止结果仍须在直播阶段设计。

## 03 DES-034 桌面聊天结构

1440×900评审基准，记录面板在舞台左侧约384×660，结束操作独立保留；人物位置与选择页一致，不随展开／收合移动或缩放。标题、输入与人工继续固定，只有消息区滚动；上翻时新消息不抢位置，提供回到最新。收合后保留可访问的记录入口，恢复原阅读位置。

外围使用轻玻璃，长文字区采用稳定表面，不给文字施加折射；消息14/24、辅助12/20、内距16。焦点可见，人物动效不作用于记录区。

### 03.1 状态与操作

| 状态 | 记录面板 | 可执行操作 |
|---|---|---|
| 新会话、暂无提问 | 人物欢迎语＋“从一句问候开始”；无虚构旧记录 | 就绪后发送 |
| 提交中／结果未知 | 原问题显示明确状态，不插入重复气泡 | 编辑草稿；核对结果，不能盲目重发 |
| 已接收／生成中 | 问题保留，人物回应占位稳定 | 草稿可编辑；发送禁用 |
| 答案就绪／播读中 | 展示生成文本，另显示真实可知的播读状态 | 不把文本完成当播放完成 |
| 等待人工继续 | 原有问答不移除，显示“听完，继续” | 符合原契约时确认，随后可提交下一问 |
| 失败／连接异常 | 本条显示原因、可用处置及持续异常条 | 根据确定状态核对／结束，不自动重播 |
| 已结束 | 本页已收到记录只读，保留滚动位置 | 返回选择；离开／新会话后不承诺保留 |

生成文本按现有最终答案协议展示，本轮不新增逐字流式接口。未接收的本地问题标为发送失败，不能展示成已完成对话；未知结果保留未知。按session_id与input_id合并更新；终止后晚到事件不能写入新会话。

### 03.2 数据与生命周期建议

前端页面内存保存完整显示记录，包含session_id、input_id、本地提交顺序、问题、可取得的答案、处理状态和必要时间。每条答案在本轮结束前进入显示记录，后续状态轮询不得覆盖旧正文。读取旧消息不重新请求模型、不重新播读、不加入模型记忆。

后端模型上下文仍为[FR-024](../requirement/25-最近三轮上下文.md)最近三轮已确认问答；无正文持久化表或任意历史查询API。现有快照必须能让页面在人工继续前取得本轮最终文本，不能让只包含最新状态的轮询丢掉旧回答；接口字段与“答案尚未取回就继续”的处理需在代码阶段前回到[共享协议](03-Vidu网页PoC最小业务设计.md)评审。刷新不承诺重建完整记录。

结束后后端清空上下文；前端只读副本建议保留到离开、刷新、关闭或新会话。旧稿中笼统“结束清除正文”对前端副本的含义以此分层建议为准，具体生命周期仍待评审。不得将完整正文写localStorage、IndexedDB或普通日志来偷偷实现长期保存。

## 04 手机结构

以390×844有效视口检查，顶部保留品牌与状态，上部人物、下部可展开记录；展开后保留人物小窗。消息内部滚动，输入避让安全区和软键盘；键盘打开可缩小人物但发送／结束必须可达，关闭后恢复。收合回到原阅读位置，不把页面竖向手势绑定为切换人物。真实手机软键盘和触屏验收尚未完成。

## 05 DES-035 独立干净播出视图

先预留16:9人物与背景合成画面，9:16归后置FR-017，不承诺透明视频。操作台尺寸、主题和收合不改变播出画幅。

| 层级 | 允许出现 | 不进入播出 |
|---|---|---|
| 画面 | 人物、背景、必要AI标识；字幕默认关闭 | 头像栏、输入框、操作按钮、私人消息、内部报错、账号和连接凭据 |
| 声音 | 指定直播会话的人物声音 | 操作提示音、私聊音频及多视图重复播放 |
| 状态 | 无来源时中性待机；失联时中性“暂时离开”画面建议 | 把静态图伪装成仍在实时回应，或自动切入别的会话 |

打开播出页只表示视图可用，不表示OBS已采集、平台已开播或观众已收到。未来分别验证本地输出、采集音视频、观众端实际效果。操作台标示输出连接及音频归属，默认避免两页同时出声；操作台监听方式、关闭控制页后的租约和断线处理都需真实协议验证。

字幕若启用，只能来自批准的公开回应；生成的完整答案不得直接标成实时已播字幕。没有播放进度依据时关闭逐字同步。操作面板尺寸、收合和主题变动不影响输出画幅；人物／场景变更需显式确认是否作用于播出。结束直播后输出进入待机，不转入私聊。

## 06 DES-036 自动读评论操作页

默认人工选评论，自动开关关闭，来源／输出未就绪时不可启用。当前设计为“选评论→生成回应→播读”；是否先念昵称／原评论、纯复读与自动放行策略仍待确认。

桌面默认只展示最新待选评论、下一条队列项与当前回应；人物约420×630，位于场景x494/y76。左面板280×320，右侧队列摘要280×286，人物下方回应560×108；未连接可扩展必要说明。侧面按需展开，不用居中列表遮挡人物。轻玻璃暗底约0.11，无装饰描边／厚阴影，文字不降透明度。

| 区域 | 规则 |
|---|---|
| 待选评论 | 只显示可加入项；加入追加末尾，忽略进入操作记录，空列表有提示 |
| 待回应队列 | 数量按实际队列计；展开336×576，按顺序显示，可逐项移回待选；设为下一条只调整尚未开始项 |
| 当前回应 | 不计入待回应数；已送播不能移出、重复加入或假称已撤回 |
| 操作记录 | 与队列分开，不影响待回应数量；示例不构成完整审计日志 |
| 暂停／断线 | 停止选取下一项；整理队列、收合、切换记录和主题都不能恢复推进；重连不自动重放积压 |

手机390×844，人物204×306，下方面板342×280，固定“评论／队列／回应／记录”四项Tabs；内部滚动，暂停和结束在外部可达。空态、未连接、无权限、失败均需明确。

自动下一条必须有可信播放完成依据；无依据停在待确认，不以固定延时判播完。未知先核对，不能盲目重发。容量、过期、去重、优先级公平性、人工输入仲裁及直播模型上下文仍待后续评审；三条Figma样例不代表容量限制。
