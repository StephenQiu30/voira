# 05 网页文字提问

需求编号：**FR-004**。范围：**网页PoC P0**。

## 01 问题与来源

体验者需要提交一个问题并判断是否已被本地后端接收。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。

## 02 范围与边界

不做语音输入、弹幕池、公开聊天广场或人工候选队列。

依赖或协作：FR-002/023。

## 03 功能要求

1. 仅接收文字，不请求麦克风或摄像头权限。
2. 空白和超长文字明确提示且保留草稿；当前设计建议trim后1—500个Unicode码点，前后端一致校验。
3. 每次主动提交关联输入ID；同ID同内容返回原记录，同ID不同内容拒绝。
4. 当前轮占用期间允许编辑草稿但不能提交；已接收不得显示为人物已回答。

## 04 确认状态与剩余问题

文字提问后回答已确认；输入契约待评审。
