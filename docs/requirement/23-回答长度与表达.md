# 23 回答长度与表达

需求编号：**FR-022**。范围：**网页PoC P0**。

## 01 问题与来源

用户需要听到简短自然的回答，避免漫长等候和播读。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。

## 02 范围与边界

长度不是语速或响应延迟承诺，不加入自动摘要或长文朗读功能。

依赖或协作：FR-019/005。

## 03 功能要求

1. 默认2—3个短句、约40—100个汉字，简单问题允许更短，最多150个Unicode码点。
2. 采用自然口语，不朗读Markdown或工具输出；不为凑字数填充内容。
3. 完整答案须校验再交给人物；超长或无效答案不截断半句话，不自动二次调用凑合输出。

## 04 确认状态与剩余问题

2026-10-25用户按推荐确认。

关联问题：Q-004（本部分已确认）。本文件为已确认的业务规则，不表示代码已实现、供应商行为已验证或真实验收通过。 预算和实际调用条件按用户安排在调用前确定。
