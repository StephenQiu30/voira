# 16 空闲主动暖场

需求编号：**FR-015**。范围：**后续候选，当前不实施**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

未来无用户互动时，操作者可能希望人物主动讲话。

来源：参考图文/源码研究及已明确后置的历史需求，2026-10-25整理。原编号/归属为FR-015，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

当前网页PoC不自动暖场，不能从参考截图推导为已获准。

依赖或协作：FR-012/025。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 只有队列空闲且显式启用时才触发，间隔和费用受控。
2. 用户互动、禁用和会话结束具有明确影响，结束后不得自动恢复暖场。
