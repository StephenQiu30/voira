# 20 本地Codex回答生成

需求编号：**FR-019**。范围：**网页PoC P0**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

本机网页需要由本地Codex产生角色答案，保持可控调用边界。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。原编号/归属为FR-019，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

本机进程不等于离线推理；人设、长度与上下文独立维护。

依赖或协作：FR-021/022/024/025。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 本机后端调用Codex，仅取得成功终态且校验后的完整最终回答；推荐每轮一次exec，不强制MCP。
2. 固定版本、模型和受限配置；不继承开发线程、任意本地文件或无关工具权限。
3. 用户问题通过受控文本输入传入，不能作为shell命令或配置；中间事件和日志不能播读。
4. 失败、超时或结束后的结果不下发，不自动重试或切到Vidu生成答案；只取消本次拥有的进程。
