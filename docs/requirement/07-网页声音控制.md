# 07 网页声音控制

需求编号：**FR-006**。范围：**网页PoC P0**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

用户需要主动开启、静音及恢复人物声音。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。原编号/归属为FR-006，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

异常正文反馈独立为FR-026；不提供混音台或直播接管。

依赖或协作：FR-011/026。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 浏览器阻止播放时给出手动启声入口；仍失败时关联异常反馈。
2. 静音和恢复只控制本地听音，不创建新会话、不等同于停止生成或停费。
3. 键盘可操作并有可见焦点；静音状态不得用作人物说完的判断。
