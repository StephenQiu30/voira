# 07 网页声音控制

需求编号：**FR-006**。范围：**网页PoC P0**。

## 01 问题与来源

用户需要主动开启、静音及恢复人物声音。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。

## 02 范围与边界

异常正文反馈独立为FR-026；不提供混音台或直播接管。

依赖或协作：FR-011/026。

## 03 功能要求

1. 浏览器阻止播放时给出手动启声入口；仍失败时关联异常反馈。
2. 静音和恢复只控制本地听音，不创建新会话、不等同于停止生成或停费。
3. 键盘可操作并有可见焦点；静音状态不得用作人物说完的判断。

## 04 确认状态与剩余问题

基础声音控制在PoC范围，交互细节待评审。
