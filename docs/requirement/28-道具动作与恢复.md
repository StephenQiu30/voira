# 28 道具动作与恢复

需求编号：**FR-027**。范围：**后续候选，当前不实施**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

未来操作者可能需要触发已启用动作或道具并恢复默认形态。

来源：参考图文/源码研究及已明确后置的历史需求，2026-10-25整理。原编号/归属为FR-009，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

不规定必须七道具三动作；当前静态坐姿和卡片不是可驱动资产。

依赖或协作：FR-009。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 未来定义道具/动作及关键词白名单、显式启用、串行触发和默认形态恢复。
2. 实际动作和恢复必须动态验证，失败保留停止/回退入口。
