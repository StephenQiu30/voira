# 28 道具动作与恢复

需求编号：**FR-027**。范围：**后续候选，当前不实施**。

## 01 问题与来源

未来操作者可能需要触发已启用动作或道具并恢复默认形态。

来源：参考图文/源码研究及已明确后置的历史需求，2026-10-25整理。

## 02 范围与边界

不规定必须七道具三动作；当前静态坐姿和卡片不是可驱动资产。

依赖或协作：FR-009。

## 03 功能要求

1. 未来定义道具/动作及关键词白名单、显式启用、串行触发和默认形态恢复。
2. 实际动作和恢复必须动态验证，失败保留停止/回退入口。

## 04 确认状态与剩余问题

后续候选，来自原FR-009中的动作部分。

关联问题：后续另定。

## 05 验收与追溯

仅登记需求候选；未分配当前DES、US/AC、实现任务或真实TC，不以未设计阻塞网页PoC。
