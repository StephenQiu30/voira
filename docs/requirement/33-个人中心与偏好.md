# 33 个人中心与偏好

需求编号：**FR-032**。用户已要求设计用户页面；本轮只交付页面与交互草案，不授权账号系统或前端实现。

## 01 目标与边界

让使用者在人物舞台之外集中查看个人资料、交流偏好和本次会话入口。用户已追加确认管理员用户管理，账户与权限设计由[FR-034](35-管理员用户管理.md)承接。个人中心改为当前用户的资料及偏好：称呼归本人账户，外观、减少动效和声音偏好仍可保存在当前设备。认证方案尚待评审；不因管理页面设计而承诺跨设备同步或长期对话历史。

## 02 功能规则

1. 舞台Header提供个人中心入口；返回时保留角色、姿态、主题及当前会话，不新建或结束媒体会话。
2. 称呼仅用于用户界面，不覆盖角色人设；建议长度1—24字符，空值和超长在字段旁反馈。资料保存成功、失败与未保存离开分别处理。
3. 明暗主题使用有可访问名称的图标按钮；减少动效和声音偏好使用Switch。减少动效初始遵循系统设置，用户可覆盖；声音偏好不能绕过浏览器播放许可。
4. 本次会话入口区分没有会话、进行中和已结束。完整记录继续遵守FR-030，不产生跨会话恢复承诺；模型三轮窗口不改变页面完整记录。
5. 普通用户只进入自己的可用AI和用量视图；管理员另有用户管理及共享AI配置入口。不在人物主舞台堆叠配置字段，隐藏入口不代替服务端鉴权。

## 03 确认与验收

用户页面设计方向已授权；账户管理方向已由用户确认；字段、偏好持久化和认证方式待评审。Figma示例称呼不代表真实账户。关联[DES-038](../design/08-个人中心与AI接入管理界面.md)、[US-011／AC-065—066](../prd/01-网页数字人PoC产品与验收标准.md#15-个人中心与ai接入管理页面)、[计划02](../plan/02-网页PoC逐功能实现与验收计划.md#11-个人中心与ai管理的设计验收)。
