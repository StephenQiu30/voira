# 09 必要诊断记录

需求编号：**FR-008**。范围：**网页PoC P0**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

开发者需要定位失败阶段，并按相同配置复现。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。原编号/归属为FR-008，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

不建设运营报表、账单产品、录播或长期聊天历史。会话上下文独立为FR-024。

依赖或协作：FR-007/025。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 关联配置、会话、输入ID和阶段时间；Codex生成、Vidu下发、首音及人工继续分开记录。
2. 区分本地估计、供应商结果和人工观察；未知不能写成功或零费用。
3. 不向普通日志写密钥、控制令牌、短期RTC凭据或默认保存问答全文；验收仅记录必要自编样本。
4. 保留恢复外部会话所需最小记录；建议已结束且结算完成后7天可清理，未决记录不自动删除。
