# 09 必要诊断记录

需求编号：**FR-008**。范围：**网页PoC P0**。

## 01 问题与来源

开发者需要定位失败阶段，并按相同配置复现。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。

## 02 范围与边界

不建设运营报表、账单产品、录播或长期聊天历史。会话上下文独立为FR-024。

依赖或协作：FR-007/025。

## 03 功能要求

1. 关联配置、会话、输入ID和阶段时间；Codex生成、Vidu下发、首音及人工继续分开记录。
2. 区分本地估计、供应商结果和人工观察；未知不能写成功或零费用。
3. 不向普通日志写密钥、控制令牌、短期RTC凭据或默认保存问答全文；验收仅记录必要自编样本。
4. 保留恢复外部会话所需最小记录；建议已结束且结算完成后7天可清理，未决记录不自动删除。

## 04 确认状态与剩余问题

只保留必要排障信息；保存细节未新增确认。

关联问题：Q-008。
