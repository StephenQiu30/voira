# 08 结束网页会话

需求编号：**FR-007**。范围：**网页PoC P0**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

用户需要结束体验并核对远端服务是否真正停止。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。原编号/归属为FR-007，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

预算和累计额度独立为FR-025；不承诺本地取消等于上游立即停费。

依赖或协作：FR-002/008/019。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 立即停止新输入、退出本地媒体，并取消本次拥有的Codex调用，丢弃结束后晚到的答案。
2. 请求Vidu挂断并核对终态；区分终止中、已结束与未知，WS关闭或本地静音不是终止证据。
3. 重复结束不新建会话；未知状态保留意图/外部ID并阻止另开。
4. 页面关闭、租约到期或后端恢复后清理残留；后端全停时依赖实际可用的供应商/人工路径。

## 04 确认状态与剩余问题

明确结束是PoC必要范围；终止语义需真实验证。

关联问题：Q-006。本文保持草案，已确认方向与待评审细节分别保留；不把文档交付写成测试通过。 预算和实际调用条件按用户安排在调用前确定。
