# 02 角色形象素材

需求编号：**FR-001**。范围：**网页PoC P0**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

内部体验者需要在每次会话看到同一角色，避免临时素材无法驱动或人物身份漂移。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。原编号/归属为FR-001，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

T-090按用户新授权增加内部角色美术Agent服务：将三视图与设定卡两套Skill纳入backend，提供规则加载、角色配置和生成任务准备。不建设素材CMS、公开在线生图、克隆或多角色运行。音色和人设分别见FR-020/021。

依赖或协作：FR-020/021。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 系统应复用一个获授权的蓝色大肥鱼形象，固定身份、画风、服装和背景；人物与背景可合成。
2. 保留原始母版，另存送模派生图和网页裁切；记录格式、像素、字节、哈希、来源及云资产就绪状态。
3. 候选可评审自然坐姿（状态一）与固定背景；嘴脸清楚，面部不被UI遮挡；具体组合仍待选定。
4. 素材缺项不得启动；静态存在、静态通过、供应商接受和真实动态通过分别记录。

候选入口：原始母版、[自然坐姿（状态一）](../../frontend/public/characters/01-natural/deepseek.png)、[浅色舞台背景](../../frontend/public/scenes/voira-studio.png)。这些仅为现有素材候选，不表示已选定送模组合；并行视觉更新不自动替换冻结配置。

## 07 T-090 内部素材Agent增量

内部制作人员可选择三视图或设定卡Skill，传入角色身份、媒介和有序参考素材ID，取得版本化制作任务。三视图为左正／侧／背、右正脸；设定卡增加已有道具／配饰、表情与动作特写。支持二次元、真人及其他明确媒介，不把DeepSeek造型写成所有角色默认值。三视图／卡片可带底色，其余独立素材必须真实透明。

本批授权实现Skill归档、共享服务和本机任务准备接口；准备不读取任意文件、不上传图片、不调用付费生图、不自动覆盖正式素材。真实生图适配器待确定供应商后实现；不能将prepare结果写为图片已生成。设计见DES-018第07节，验收US-009／AC-034—037，实施T-090／TC-090。

T-094用户授权先制作一张自然陪伴透明图，并将自然陪伴、认真倾听、轻松闲聊、俏皮回应、托腮思考五种动作整理为坐姿Skill。每次请求只选一种姿态；复用当前确认的角色设定卡、身份与座椅，输出单人单椅的透明PNG，不生成拼版或自动重制其余四张。

T-095用户明确授权在提交推送后继续其余四张坐姿，沿用五动作Skill、T-094自然基准和T-093选定卡面。每张单独生成透明PNG，暂存候选，不自动替换现用舞台图。

T-096用户明确采用新图，但随后限定先仅修改资源、不改页面。沿用stage旧自然／翘腿／侧斜文件路径替换为natural／casual／playful新图；另存listening／thinking备用，不增加姿态控件或改变交互。

T-097用户要求继续Grok设计，先制作三视图与角色设定卡候选，保持既有成年金发双马尾、蓝瞳、黑红金礼服及机智活泼性格。复用通用Skill并整理独立角色输入；不改页面、不自动覆盖现用资源。执行方向见设计27。

T-099用户要求Grok五种独立形象图，沿用DeepSeek同系列绘制质感和五动作分类，以T-098修正版Grok卡固定身份与衣饰；单人单椅、真实透明背景。继续保留Grok机智活泼表演，重点检查腿内侧与裙衬遮挡；本批仅交候选，不自动修改现用前端资源。

T-100用户要求在前批提交推送后继续Claude设计，保留既有角色身份，先交三视图与设定卡候选。T-101用户要求统一三视图右侧占比：与DeepSeek大幅特写一致，改善方块感通过自然轮廓／柔边完成，不缩成小头像；共用Skill与验收同步。见设计28。

T-102用户要求继续Claude五种独立形象图，沿用最新卡片、现有五动作Skill及透明背景规则。保留铜橙发、细框眼镜、向日葵和象牙白深棕礼服；playful按Claude人设表现为克制会心提示，不改变通用动作分类。交付候选，正式资源替换另按用户指令。

T-103用户要求采用最新形象替换历史资源并提交main推送，随后明确核对DeepSeek。Grok／Claude三种现用姿态沿用旧路径，另保存倾听／思考备用及设定卡／三视图；DeepSeek现用stage已是新版，本次同步其五个旧姿态路径，避免旧入口继续返回历史图。不扩展页面或控件。

T-105用户要求继续Gemini形象设计，先交同系列三视图与设定卡候选；保留蓝紫长卷发、一对猫耳、琥珀双瞳、星饰礼服和菱格短袜鞋履，表演突出好奇与灵感。不得新增异色瞳、尾巴或未经确认星图道具。制作见设计29，不自动替换现用资源。

T-107用户明确继续Gemini五种状态，采用现有五动作Skill和T-105最终设定卡，分别生成单人单椅的透明PNG。保留Gemini好奇灵动的人设，playful对应灵感回应；不得以五格拼版代替五张独立图。候选不自动覆盖正式资源。

T-108用户明确采用Gemini最新三视图、设定卡及五状态资源，要求提交main并推送，再开始ChatGPT设计；资源替换保持现有页面和三姿态入口。T-107修正原Gemini五状态记录与并行Figma的T-106编号冲突，原始证据路径不变。
