# 02 角色形象素材

需求编号：**FR-001**。范围：**网页PoC P0**。

## 01 问题与来源

内部体验者需要在每次会话看到同一角色，避免临时素材无法驱动或人物身份漂移。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。

## 02 范围与边界

内部角色美术服务提供三视图、设定卡与独立坐姿三套Skill，负责规则加载、角色配置和任务准备。不建设素材CMS、公开在线生图、克隆或多角色运行。音色和人设分别见FR-020/021。

依赖或协作：FR-020/021。

## 03 功能要求

1. 每位角色使用获授权、版本明确的素材，固定该版本身份、画风、服装和背景；人物与背景可合成。七位范围按FR-031，蓝色大肥鱼为早期验证基线。
2. 保留原始母版，另存送模派生图和网页裁切；记录格式、像素、字节、哈希、来源及云资产就绪状态。
3. 候选可评审自然坐姿（状态一）与固定背景；嘴脸清楚，面部不被UI遮挡；具体组合仍待选定。
4. 素材缺项不得启动；静态存在、静态通过、供应商接受和真实动态通过分别记录。

候选入口：原始母版、[自然坐姿（状态一）](../../frontend/public/characters/01-natural/deepseek.png)、[浅色舞台背景](../../frontend/public/scenes/voira-studio.png)。这些仅为现有素材候选，不表示已选定送模组合；并行视觉更新不自动替换冻结配置。

## 04 确认状态与剩余问题

七位角色方向已确认，前五位已有正式静态图；Kimi／Qwen尚无正式图。各角色具体送模版本与动态观感仍待评审。

关联问题：Q-004。

## 06 内部制作能力

内部制作人员选择三视图、设定卡或单一坐姿，传入角色、媒介和有序参考ID，得到含规则版本的prepared任务。支持二次元、真人等明确媒介；角色身份独立于通用Skill，不能让DeepSeek造型成为全体默认。三视图／整卡允许底色，其余独立素材须真实透明。

五态固定为自然陪伴、认真倾听、轻松闲聊、俏皮回应、托腮思考；每次只准备一张单人单椅图，不以拼版替代独立图片。自然基准通过后再制作其余姿态。角色差异通过表情和仪态体现，动作分类统一。

prepare不读任意路径、不上传、不调用真实生图、不自动覆盖正式素材；真实适配器须另实现。现行规则／造型与采用资源归[视觉设定20](../design/20-人物三视图视觉设定.md)，运行提示词归backend Skill与profiles，服务契约见[DES-018](../design/04-角色形象素材设计.md#06-内部素材任务准备服务)。验收为US-009／AC-034—059，历史路径条件以PRD标明的替代关系为准。
