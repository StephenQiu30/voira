# 03 开始网页会话

需求编号：**FR-002**。范围：**网页PoC P0**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

用户需要一次明确操作进入真实人物会话，理解创建和连接进度。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。原编号/归属为FR-002，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

不提供房间列表、公众账号或自动续开。结束与预算各自独立。

依赖或协作：FR-001/020/019/025。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 校验素材、声音、Codex配置和调用额度后才创建会话；打开网页或接口文档不自动创建。
2. 重复开始或响应丢失只保留同一创建意图；单机同一时刻只有一个未结清会话。
3. 创建、控制连接、媒体加入和真实首帧分开反馈；创建超时先核对残留，不盲目重建。
