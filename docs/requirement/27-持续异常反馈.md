# 27 持续异常反馈

需求编号：**FR-026**。范围：**网页PoC P0**。本文只维护这一项功能；[总索引](01-数字人MVP需求草案.md)维护阶段范围与共享约束。

## 01 问题与来源

用户需要在故障时看清发生了什么并能结束体验。

来源：用户直接确认及既有网页PoC需求，2026-10-25整理。原编号/归属为FR-006/011，见[拆分前v0.9快照](history/01-数字人MVP需求草案-v0.9.md)；参考证据见[调研索引](../research/00-调研索引.md)。本次T-023仅拆分已有行为，不新增功能授权。

## 02 范围与边界

不提供全天自愈、备用节目或无感切换；普通重试不能隐含重复生成。

依赖或协作：FR-007/011。跨功能约束引用[共享NFR](01-数字人MVP需求草案.md#05-非功能性需求)，不在本文复制第二份架构或接口契约。

## 03 功能要求

1. 连接/媒体/状态查询失败后，错误持续显示于页面正文，不能仅用Toast或继续显示可用。
2. 停止新增输入并提供结束/核对入口；无回应、生成失败和发送未知不能显示已完成。
3. 旧会话事件、旧revision与晚到结果不得污染当前界面；刷新不自动新建收费会话。
